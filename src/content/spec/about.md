# About

**CPC (Competitive Programming Contest)** 是一项旨在考察程序设计和算法能力的团队比赛。参赛者通常需要在有限的时间内解决多个编程问题，并且需要良好的团队合作与沟通能力。比赛题目涵盖算法、数据结构、数学、逻辑推理等多个方面，考验参赛者的综合能力。

**创中 CPC 组** 是由大连理工大学的算法竞赛爱好者组成的团队，致力于为同学们提供一个共同学习、练习、参加比赛的平台。我们定期组织训练、讲座，并参与国内外的各类编程竞赛。**ICPC 和 CCPC** 是全球顶级的大学生编程竞赛，创中 CPC 组是这些赛事的常客，我们也鼓励所有对编程竞赛有兴趣的同学加入，并参与这些赛事。

如果你对编程、算法和竞赛有兴趣，欢迎加入我们！你可以：

- 加入我们的招新QQ群（见 [CPC 组内资源](https://dlut-cpc.github.io/posts/cpc-team-resources.html)），这里是我们的讨论区和交流平台；
- 来到教学区 A316，现场了解更多信息并与我们交流。

我们期待你的加入，一起在编程的世界里成长与进步！
